# Release v0.5.0

<p align="center">
  <img src="https://github.com/kopecmaciej/vi-sql/blob/master/assets/logo.svg"/>
</p>

Minor release adding batch cell editing to the table data view.

## Features

- **Batch cell edit** — press `v` in the data view to select a rectangle of cells, then `e` to edit them together. The new value is written to every selected row in a single transaction that commits only if all rows succeed, otherwise it rolls back. `NULL` is supported via a typed sentinel. (by @pauldo, [#83](https://github.com/kopecmaciej/vi-sql/pull/83))
- **Contextual footer keys** — the footer keybinding hints now update while cell (`v`) or row (`V`) visual selection is active, showing the keys relevant to the current selection mode. ([#85](https://github.com/kopecmaciej/vi-sql/pull/85), refs [#84](https://github.com/kopecmaciej/vi-sql/issues/84))
