# Release v0.3.0

Minor release adding GaussDB support, search through query results, and more consistent boolean display.

## Features

- **GaussDB driver (by @AndrewDi, [#70](https://github.com/kopecmaciej/vi-sql/pull/70))** — vi-sql now supports connecting to GaussDB databases, including queries, schema browsing, and pagination.
- **Search through results** — query results can now be searched with keyboard-driven navigation. ([#72](https://github.com/kopecmaciej/vi-sql/pull/72))

## Fixes

- **Boolean display** — PostgreSQL and peeker boolean values are now normalized and displayed consistently.

## Thanks

Thanks to everyone who contributed to this release.
